## 📌 About the Project

**Forge Fitness** is a creative gym landing page designed to provide a bold and engaging user experience.

The website focuses on:

* Modern gym branding
* Responsive design
* Smooth animations
* Interactive elements
* Membership plans
* Fitness classes
* Strong call-to-action sections

The goal was to create a professional landing page that works smoothly across desktop, tablet and mobile devices.
